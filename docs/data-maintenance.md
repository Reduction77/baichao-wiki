# 数据维护与迁移核对记录

本文面向站点维护者。玩家页面仅展示来源、版本、更新时间和更新状态。

## 数据更新

更新与配队视频库分别维护。正常访问使用已保存的数据和图片，不请求上游配置。

正式服更新使用 `python3 tools/import_github_archive.py`，随后运行 `python3 tools/build_catalog_order.py` 与 `python3 tools/build_team_profiles.py`，检查正式服状态、配置结构、图片覆盖和测试服排除情况。完整操作及打包流程见 [README](../README.md)。

更新检查结果位于 `web/data/source-status.json`，不会自动替换当前资料。配队配置维护方式见 README 的配队工作台部分。
