# 配队工作台练度导入

2026-11-03 从练度导入预览第 14 版迁入（源提交 `0f3b7d4bf50b6cfafdf36b2959dc09cf7d4e006a`）。正式站继续读写 `baichao-team-builder-v1`，保留已有队伍、当前编队与可用名单；不切换到预览存档。练度记录使用 `baichao-training-v1`，撤销备份使用 `baichao-training-import-backup-v1`。

工作台提供单张完整的单列 ww 练度长图导入，限制 15 MB、1600 万像素。识别在浏览器本地执行；结果经核对并点击应用后才保存。角色、评分、评级、共鸣链、五星武器名称及阶数可人工调整；低星武器不保存阶数。识别不保证准确，模糊图、相似头像和未收录武器需要人工核对。

每次应用都将勾选角色设为可用，其余角色设为不可用；补充模式保留其他练度记录和已有有效字段，替换模式仅保留本次练度资料。已存队伍、草稿与收藏保留。撤销会恢复导入前的可用角色名单和练度资料，同时保留后来调整的队伍。恢复 JSON 备份会在确认后替换工作台与练度资料。

预览站和正式站属于不同来源，浏览器数据不会自动跨站同步。在预览站导出“备份练度与配队”，再在正式站恢复即可手动迁移；恢复会替换正式站当前配队，请先备份。

同步包含紧凑编队、两列推荐和定位筛选、错误行定位、默认勾选已识别行、取消识别清理、可用名单联动、次数冲突检查和 100 队上限。角色、武器、推荐队伍与矩阵规则沿用正式 Wiki 数据。

维护时运行 `python3 tools/build-training-catalog.py` 从正式站资料重建武器词典；新增角色还需维护 `web/data/training-templates.json` 中的默认头像路径。运行时、模型及许可证保存在 `web/assets/training/vendor/`，来源和 SHA-256 见其 NOTICE.md 与 manifest.json。图片和识别记录不会上传至服务器。

发布检查包含原有 Wiki 回归和五套 `tools/test-training-*.mjs`。`tools/test_team_builder.mjs` 额外验证开启练度导入后继续读写正式站存档。Node 模拟检查不替代手机性能或新样图的识别准确率测试。
